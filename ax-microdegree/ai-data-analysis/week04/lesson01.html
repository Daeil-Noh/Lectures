나
근무조별 불량률을 비교하고 싶어. process.csv의 shift(주간/야간), defect(0/1) 열을 써. pandas만, 주석 달아서. 결과는 %로 소수 첫째 자리까지.
AI의 답 (예시)
import pandas as pd
df = pd.read_csv(DATA + 'process.csv')
# 근무조별 불량률(%) = defect(0/1)의 평균 × 100
rate = df.groupby('shift')['defect'].mean() * 100
print(rate.round(1))
바로 실행됨 — 야간 20.3 · 주간 7.0

# ① 데이터 불러오기: 표 전체가 df에 담긴다
df = pd.read_csv(DATA + 'process.csv')

# ② shift(주간/야간) 값이 같은 행끼리 묶고,
#    각 묶음에서 defect의 평균을 구한다
#    defect는 0/1이므로 평균 = 불량 비율
rate = df.groupby('shift')['defect'].mean()

# ③ 비율 × 100 → %, 소수 첫째 자리로 반올림
print((rate * 100).round(1))
