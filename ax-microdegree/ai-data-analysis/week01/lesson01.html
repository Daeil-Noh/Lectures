② AI란?

AI를 이해하는 질문 하나: 규칙을 누가 만드는가?

전통적인 프로그래밍
사람이 규칙을 쓴다
if 두께 < 1.75mm : 불량
변수가 수십 개면? 규칙을 빠짐없이 쓰기 어렵다
머신러닝
컴퓨터가 데이터에서 찾는다
과거 데이터 + 정답(양품/불량) → 규칙(모델)
AI = 사람의 지적 능력이 필요한 일을 컴퓨터가 하게 만드는 기술
