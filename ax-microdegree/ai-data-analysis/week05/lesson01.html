HTTPError: HTTP Error 404: Not Found
→ 404 = 그 주소에 파일이 없다. 철자·대소문자·슬래시(/) 확인

FileNotFoundError: [Errno 2] No such file or directory: 'proces.csv'
→ 파일을 올렸는지, 이름이 정확한지 확인
한글이 깨진 CSV
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xb0
→ 국내 엑셀·공공데이터에 흔함. pd.read_csv(파일, encoding='cp949')
