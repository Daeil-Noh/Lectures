오류값은 지우지 말고 NaN으로 바꾼다

import numpy as np                     # NaN 을 쓰려고

# 센서 오류 코드 999.9, -1.0 → 빈칸(NaN)
df['temp'] = df['temp'].replace([999.9, -1.0], np.nan)

df['temp'].isna().sum()                # → 8
round(df['temp'].mean(), 2)            # → 211.47
# 오류 코드를 모를 때: 정상 범위 밖을 NaN 으로
bad = (df['temp'] < 150) | (df['temp'] > 300)
df.loc[bad, 'temp'] = np.nan
1
왜 행을 지우지 않나? 그 제품의 압력·두께·불량 기록은 멀쩡하다. 틀린 칸만 비운다
2
NaN은 평균·합계 계산에서 자동으로 빠진다 → 평균 211.47℃로 정상화
3
범위 기준(150~300℃)은 설비 사양·현장 담당자에게 확인하고, 정한 이유를 기록한다

② 결측치 처리

평균으로 채울까, 중앙값으로 채울까?

평균 mean()
모든 값을 더해 나눈다 → 극단값 하나에 끌려간다
중앙값 median()
줄 세워 가운데 값 → 극단값에 거의 흔들리지 않는다. 치우친 분포·이상값이 의심되면 중앙값

순서가 중요: ① 오류값을 NaN으로 → ② 그다음 채우기. 거꾸로 하면 999.9가 섞인 평균으로 빈칸을 채우게 됩니다.
