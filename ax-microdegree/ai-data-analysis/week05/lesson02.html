② 조건으로 행 고르기

조건 두 개 묶기: & 그리고, | 또는

df[(df['temp'] > 220) & (df['shift'] == '야간')]

조건마다 괄호 ( )가 꼭 필요합니다. 빠뜨리면 계산 순서가 꼬여 오류:

TypeError: unsupported operand type(s) for &: …

파이썬의 and·or는 표에 쓸 수 없습니다 → ValueError: The truth value of a Series is ambiguous. 반대 조건은 ~ (아님).

② 조건으로 행 고르기

  
골랐으면 세어 보고, 고른 것끼리 계산하기

  

    

      
hot = df[df['temp'] > 220]      # 고른 결과를 변수에 담기

len(hot)                        # 행 개수 → 49
(df['temp'] > 220).sum()        # True 개수 → 49
(df['temp'] > 220).mean()       # True 비율 → 0.099

hot['defect'].mean()            # 고른 행의 불량률 → 0.429
df.loc[df['temp'] > 220, ['product_id', 'temp']]   # 행·열 함께

    

    

      
1
True는 1, False는 0으로 계산 → sum() = 개수, mean() = 비율 (전체의 9.9%)

      
2
고른 행끼리 평균을 내면 질문에 답이 된다: 220℃ 초과 제품의 불량률 42.9% (전체 13.8%)

      
3
df.loc[조건, 열 목록]은 행과 열을 한 번에 고른다

      
“온도가 높으면 불량이 많다”고 바로 결론 내리긴 이릅니다. 다른 조건도 함께 달라졌을 수 있습니다 — 7주차 상관과 인과에서.

AI가 만든 조건 코드, 그대로 믿어도 될까?

  

    

      
 “df에서 온도가 220℃를 넘는 야간 제품만 골라 개수를 세는 pandas 코드를 써 줘. 열 이름은 temp, shift이고 값은 '주간'/'야간'이야.”

      
 AI가 준 코드 (예시)

      
result = df[(df['temp'] >= 220) & (df['shift'] == '야간')]
print(len(result))

① 경계값: 넘는다 = >
“넘는”은 초과인데 >=(이상)를 썼다. 정확히 220.0인 제품이 섞여 33 → 34

      
② 다른 방법으로 다시 세기
((df['temp'] > 220) & (df['shift'] == '야간')).sum() → 33

      
③ 결과 몇 행을 눈으로
result['temp'].min(), result['shift'].unique()로 조건이 지켜졌는지 확인
