③ 함수·라이브러리

  
총동원: 494개 중 220℃ 초과 세기

  

    

      
import pandas as pd
DATA = 'https://raw.githubusercontent.com/Daeil-Noh/Lectures/main/ax-microdegree/ai-data-analysis/data/'
df = pd.read_csv(DATA + 'process.csv')   # 표로 읽기
temps = df['temp'].tolist()              # 온도 열 → 리스트
count = 0
for t in temps:
    if t > 220:
        count = count + 1
print(len(temps), count)

      
494 49

    

    

      
1라이브러리: import pandas as pd

      
2함수: pd.read_csv( )로 CSV를 표(df)로

      
3리스트·변수: 온도 열을 temps에

      
4반복 + 조건: 220 초과면 count + 1

      
5주차 예고: pandas로는 한 줄!
(df['temp'] > 220).sum() → 49
