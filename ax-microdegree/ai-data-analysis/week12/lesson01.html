③ k 고르기·표준화

표준화: 모든 변수를 “표준편차 몇 개”로 바꾼다

표준화 값 = (값 − 평균) ÷ 표준편차

평균표준편차제품 B → 표준화
온도211.4℃7.39℃212.5℃ → +0.14
두께1.999mm0.065mm1.856mm → −2.20

이제 두께가 평균보다 표준편차 2개 넘게 얇다는 사실이 온도와 같은 무게로 거리에 반영됩니다.

from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

X = df[['temp', 'thickness']]   # 묶을 변수 2개
# 표준화: 열마다 평균 0, 표준편차 1로
X_s = StandardScaler().fit_transform(X)

km = KMeans(n_clusters=3, n_init=10,
            random_state=0)
df['cluster'] = km.fit_predict(X_s)   # 무리 번호

n_init=10: 시작 위치를 10번 바꿔 가장 촘촘한 결과를 고른다 · random_state=0: 매번 같은 결과
