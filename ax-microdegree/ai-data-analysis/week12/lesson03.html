셀 3: 설비마다 “평소 기준” 붙이기

▶셀 3 · 정상 기준 구간 1~60일
BASE = 60                       # 정상 기준 구간: 1~60일
normal = vib[vib['day'] <= BASE]
base = normal.groupby('machine')['rms'].agg(['mean', 'std'])
# 각 행에 그 설비의 평균·표준편차 붙이기
vib = vib.merge(base, on='machine')

vib['z'] = (vib['rms'] - vib['mean']) / vib['std']   # z-점수
base.round(3)

셀 4·5: 설비별 7일 이동평균, 그리고 z > 3 경보

▶셀 4 · 이동평균 (설비별로!)
W = 7
vib['rms_ma'] = vib.groupby('machine')['rms'].transform(
    lambda s: s.rolling(W).mean())
vib['z_ma'] = (vib['rms_ma'] - vib['mean']) / vib['std']
▶셀 5 · 경보
K = 3
vib['alarm_z'] = vib['z'] > K        # 원래 값으로 3σ
vib['alarm_ma'] = vib['z_ma'] > K    # 이동평균으로 3σ
vib.groupby('machine')[['alarm_z', 'alarm_ma']].sum()

True/False 열을 sum() 하면 True(경보)인 날의 수. 이동평균은 정상 설비의 경보 1 → 0. 셀 4의 출력: 3호기 27일 z 3.42 → 이동평균 z 0.28.
groupby 없이 vib['rms'].rolling(7) 을 하면 1호기 마지막 날과 2호기 첫날이 한 평균에 섞입니다.

셀 6: 정상 구간으로 학습하고, 전체를 판정

▶셀 6 · IsolationForest
feats = ['rms', 'temp', 'current']
model = IsolationForest(contamination=0.01,
                        random_state=0)
model.fit(vib.loc[vib['day'] <= BASE, feats])   # 6대 × 60일

vib['alarm_if'] = model.predict(vib[feats]) == -1
# 이상 점수: 클수록 이상
vib['score_if'] = -model.score_samples(vib[feats])
vib.groupby('machine')['alarm_if'].sum()
