② 정밀도·재현율

세 가지 눈금, 세 가지 질문

정확도 accuracy
“전체 중 몇 개 맞혔나?”
(잡은 불량 + 정상 통과) ÷ 전체
(9 + 126) ÷ 149 = 90.6%
정상이 많으면 저절로 높아진다
정밀도 precision
“불량이라고 한 것 중 진짜 불량은?”
잡은 불량 ÷ (잡은 불량 + 잘못 경보)
9 ÷ 11 = 81.8%
낮으면 경보가 자주 헛울린다
재현율 recall
“진짜 불량 중 몇 개를 잡았나?”
잡은 불량 ÷ (잡은 불량 + 놓친 불량)
9 ÷ 21 = 42.9%
낮으면 불량이 고객에게 간다

같은 나무, 같은 판정인데 90.6% · 81.8% · 42.9%. 어느 숫자를 보고하느냐에 따라 전혀 다른 이야기가 됩니다.

③ 판정 기준

공장에서는 어떤 오류가 더 비쌀까?

놓친 불량 (FN)
  • 불량품이 고객에게 출하 → 반품·클레임
  • 안전 부품이면 사고·리콜 위험
  • 회사 신뢰도 하락
이 비용이 크면 → 기준을 낮춰 재현율을 올린다
잘못 경보 (FP)
  • 재검사 시간·인건비
  • 멀쩡한 제품 폐기, 라인 정지
  • 경보가 잦으면 작업자가 경보를 무시
이 비용이 크면 → 기준을 높여 정밀도를 올린다

③ 판정 기준

코드로 기준 바꾸기: predict_proba + 비교

proba = model.predict_proba(X_test)[:, 1]   # 불량 확률
for t in [0.2, 0.3, 0.5, 0.9]:
    p = (proba >= t).astype(int)      # 기준 이상 → 1(불량)
    tn, fp, fn, tp = confusion_matrix(y_test, p).ravel()
    print(t, tp, fn, fp,
          round(precision_score(y_test, p), 3),
          round(recall_score(y_test, p), 3))
