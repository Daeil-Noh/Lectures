① 가운데는 어디?

평균을 쓸까, 중앙값을 쓸까?

좌우가 고르면
평균 ≈ 중앙값 → 어느 쪽이든 괜찮다. 보통 평균을 쓴다
온도: 평균 211.4 · 중앙값 211.6
한쪽에 극단값이 있으면
평균이 끌려간다 → 중앙값이 ‘보통’을 더 잘 보여 준다
예: 설비 수리 시간, 납품 대기 일수
둘이 많이 다르면
데이터에 극단값이나 오류가 있다는 신호 → 원본을 들여다본다
정리 전 온도: 220.1 vs 211.6

덧붙여: 불량 유형처럼 글자로 된 값은 평균을 낼 수 없으니 가장 많이 나온 값(최빈값)을 씁니다. 예: 불량 68개 중 가장 많은 유형은 치수불량(30개).

② 얼마나 퍼져 있나?

퍼짐을 재는 세 가지 자

범위 = 최댓값 − 최솟값
216.1 − 198.5 = 17.6℃ · 간단하지만 점 두 개만 본다
분산 = 편차²의 평균
편차 = 값 − 평균. 제곱해서 +/−를 없앤 뒤 평균 → 25.7 (단위 ℃²)
표준편차 = √분산
원래 단위로 되돌린 값 → 5.1℃ · “평균에서 보통 이만큼 떨어져 있다”

열 하나를 골라 통계 메서드 붙이기

import pandas as pd
DATA = '…/data/'          # 전체 주소는 실습 파일에
df = pd.read_csv(DATA + 'process.csv')

s = df['strength']              # 인장강도 열 하나
print(round(s.mean(), 2))       # 평균
print(round(s.median(), 2))     # 중앙값
print(round(s.max() - s.min(), 2))  # 범위
print(round(s.var(), 2))        # 분산
print(round(s.std(), 2))        # 표준편차

round(값, 2): 소수 둘째 자리까지 반올림해서 보기 좋게

.var() .std()분산 9.93 MPa², 표준편차 3.15 MPa — 해석은 표준편차로
