② 직선 규칙과 잔차

예측 규칙: 강도 = a × 압력 + b

a · 기울기
압력이 1 bar 늘 때 강도가 평균적으로 얼마나 늘어나는가
b · 절편
직선의 높이를 맞추는 값. 압력 0 bar 는 데이터에 없으니 뜻을 따지지 않는다
데이터에서 찾은 규칙 (494개)
강도 = 0.36 × 압력 + 10.0
예: 0.36 × 85 + 10.0 = 40.6 MPa

③ 가장 좋은 직선

잔차를 그냥 더하면 안 되는 이유

그냥 더하면 (+2) + (−2) + (+1) + (−1) = 0
다 틀렸는데 “오차 0”? +와 −가 서로 지워진다
제곱해서 더하면 4 + 4 + 1 + 1 = 10
모두 양수가 되고, 큰 잔차일수록 더 크게 벌점을 준다

잔차 제곱을 모두 더한 값 = 오차 제곱합. 이 값이 가장 작은 직선을 고른다 → 최소제곱법

③ 가장 좋은 직선

컴퓨터에게 시키면: 코드 몇 줄

from sklearn.linear_model import LinearRegression

X = df[['pressure']]        # 입력: 압력 (표 모양)
y = df['strength']          # 정답: 인장강도

model = LinearRegression()  # 직선 모델 준비
model.fit(X, y)             # 학습: 최소제곱 직선 찾기
print('기울기 a =', round(model.coef_[0], 3))
print('절편 b =', round(model.intercept_, 2))
기울기 a = 0.359
절편 b = 9.97
X 와 y
X = 입력(특성), y = 맞힐 정답(목표). X 는 대괄호 두 겹 [[ ]] 로 표 모양
fit = 학습
