② 나누는 방법 · 코드

train_test_split 한 줄이면 된다

from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error as mae

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=0)
print(X_train.shape, X_test.shape)

model = DecisionTreeRegressor(random_state=0)
model.fit(X_train, y_train)          # train으로만 학습
tr = mae(y_train, model.predict(X_train))
te = mae(y_test, model.predict(X_test))
print(round(tr, 2), round(te, 2))    # 훈련, 시험 오차
(395, 5) (99, 5)
0.0 1.93
1
받는 순서가 정해져 있다. X_train, X_test, y_train, y_test — 순서를 바꿔 쓰면 엉뚱한 데이터가 들어간다
2
test_size=0.2 시험용 20% → 99행, 훈련용 80% → 395행
3
random_state=0 섞는 방법을 고정하는 번호. 같은 번호면 몇 번을 실행해도 같은 결과 → 다른 사람도 재현할 수 있다
4
fit에는 train만. test는 마지막 채점에만 — 훈련 0.00, 시험 1.93

③ 공정하게 나누기 · 코드

stratify: 정답의 비율을 지켜서 나눈다

y = df['defect']           # 정답: 불량 여부

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=3,
    stratify=y)            # y의 비율대로 나누기

print(round(y_train.mean(), 3), round(y_test.mean(), 3))
0.137 0.141

stratify 없이 같은 random_state=3 으로 나누면 → 0.149 0.091 (시험 데이터 불량 9개)

1
층화(stratify). 양품 무리와 불량 무리를 각각 8:2로 나눠 합친다 → 양쪽 불량률이 전체와 거의 같다
2
언제 쓰나? 분류 문제, 특히 불량·고장처럼 한 범주가 드물 때. 시험 데이터에 불량이 거의 없으면 불량을 잘 잡는지 채점조차 못 한다
3
회귀에서는? 정답이 숫자라 보통 쓰지 않는다. 오늘 실습의 강도 예측은 stratify 없이 나눈다
