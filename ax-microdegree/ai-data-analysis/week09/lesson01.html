    첫 머신러닝 코드: 압력으로 강도 예측

    from sklearn.linear_model import LinearRegression

X = df[['pressure']]        # 입력 X (표 모양)
y = df['strength']          # 정답 y (열 하나)

model = LinearRegression()  # 모델: 직선 회귀
model.fit(X, y)             # 학습

new = pd.DataFrame({'pressure': [70, 80, 90]})
print(model.predict(new).round(2))   # 예측
    [35.08 38.66 42.25]

    새 조건을 predict. 압력 70·80·90 bar 제품의 강도를 숫자로 답한다 → 회귀
