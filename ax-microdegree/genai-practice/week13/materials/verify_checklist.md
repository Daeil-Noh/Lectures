# “진짜일까?” 공유 전 확인 점검표

이미지·음성·영상·글 어떤 것이든, **공유하거나 돈을 보내기 전에** 아래 다섯 가지를 확인합니다.
확인이 끝나지 않았다면 판정은 “보류”이고, **공유도 보류**합니다.

| 단계 | 질문 | 확인 결과 (의심 신호 / 믿을 근거 / 참고) |
|---|---|---|
| ① 멈추기 | 화나게 하거나, 무섭게 하거나, 서두르게 만드는가? (“오늘까지”, “비밀로”, “지금 바로”) | |
| ② 출처 | 누가 처음 올렸나? 공식 계정·공식 누리집인가? 철자가 비슷한 사칭은 아닌가? | |
| ③ 원본 | 이미지로 검색하면 더 오래된 원본이 나오는가? 다른 곳·다른 날짜의 사진은 아닌가? | |
| ④ 맥락 | 날짜·장소·상황이 내용과 맞는가? 사진 속 배경·글자·계절이 맞는가? | |
| ⑤ 교차 확인 | 믿을 만한 다른 곳(공식 공지, 여러 언론, 관계 기관)에도 같은 내용이 있는가? | |

**판정**: □ 사실로 확인됨  □ 가짜일 가능성 높음  □ 사실과 다름(맥락 오류)  □ 아직 판단 보류

## 전화·영상통화로 돈이나 정보를 요구받았다면
- 목소리·얼굴이 똑같아도 확인이 아닙니다. 목소리와 얼굴은 AI로 흉내 낼 수 있습니다.
- 전화를 끊고 **내가 원래 알고 있는 번호·경로**로 다시 연락해 확인합니다.
- 미리 정해 둔 **확인 질문(암호)** 을 묻고, 다른 사람에게도 알립니다.
- 이미 송금했다면 즉시 은행에 지급정지를 요청하고 경찰(112)에 신고합니다.

## 피해를 입었다면
1. 원본을 다시 퍼뜨리지 않습니다.
2. 화면 캡처, 주소(URL), 날짜·시간을 기록해 증거를 남깁니다.
3. 플랫폼 신고 기능과 경찰(112)에 신고합니다.
4. 성적 합성물 피해는 디지털성범죄피해자지원센터(02-735-8994)에서 상담·삭제 지원을 받을 수 있습니다.

※ 생성형AI에게 “주장 나누기·확인할 곳 찾기”는 도움을 받을 수 있지만, 진짜·가짜 최종 판정은 원래 출처에서 직접 확인합니다.
