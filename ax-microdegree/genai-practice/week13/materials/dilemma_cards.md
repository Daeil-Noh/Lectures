# 딜레마 카드 토론지

정답이 분명한 카드도 있고, 의견이 갈리는 카드도 있습니다. 먼저 **내 선택**을 적고, 그 **이유**를 한두 문장으로 씁니다. 그다음 반대 관점을 한 가지 이상 적어 봅니다.

| # | 상황 (모두 가상) | 내 선택 | 이유 | 반대 관점 |
|---|---|---|---|---|
| 1 | 보고서는 직접 썼고 AI에게 문장만 다듬어 달라고 했다. 제출할 때 AI 사용을 밝힐까? | | | |
| 2 | 후기 답글을 AI 초안으로 쓰고 직원이 고쳐 올린다. 고객에게 알릴까? | | | |
| 3 | AI 점수 하위 절반 지원자는 서류를 읽지 않고 탈락시키자는 제안. 찬성? | | | |
| 4 | 간식 할인 쿠폰 광고를 20~30대에게만 보여 준다. 괜찮을까? | | | |
| 5 | 동료가 AI가 정리한 매출 수치를 확인 없이 보고서에 넣었다. 틀린 것 같다. | | | |
| 6 | 홍보 이미지 프롬프트에 “○○ 작가 스타일로”라고 쓴다. 괜찮을까? | | | |

## 생각을 정리하는 질문
- 이 결정으로 **누가 영향을 받는가?** (고객, 지원자, 동료, 작가, 회사)
- 그 사람이 이 사실을 **알게 되면** 어떻게 느낄까?
- AI가 틀렸을 때 **누가 확인하고, 누가 책임지는가?**
- 수업·회사·플랫폼의 **규칙**은 무엇이라고 하는가?
