## 3. 고르는 기준
- [ ] 페르소나의 고민에 답한다
- [ ] 근거(후기·가격 등)를 확인할 수 있다 — AI가 지어낸 연혁·수상·수치가 없다
- [ ] 채널의 길이·형식에 맞는다 (해시태그는 3~5개 이내)
- [ ] 핵심 메시지가 그대로 살아 있다

## 4. 표시·광고 점검 (식품)
- [ ] 질병 예방·치료, 의약품처럼 보이는 표현이 없다
- [ ] 체중 감량·면역력 등 건강기능식품으로 오인될 표현이 없다
- [ ] “최고·100%·무조건” 같은 근거 없는 과장이 없다
- [ ] 다른 회사 제품을 깎아내리거나 근거 없이 비교하지 않았다
- [ ] 성분·수치 표현이 제품 포장의 표시와 같다
- [ ] 대가를 받은 후기·추천이면 “광고/협찬”을 제목·첫 부분에 밝혔다
- [ ] 광고 문자라면 수신 동의, “(광고)” 표시, 무료 수신거부 방법을 지켰다
