# 바다결 업무 프롬프트 템플릿 모음 (v1)

쓰는 법
1. 필요한 템플릿을 통째로 복사한다.
2. 대괄호 [ ] 로 된 빈칸을 내 상황에 맞게 바꿔 쓴다. (대괄호는 지운다)
3. 맨 아래 자료 칸에 회의 메모·문의 내용 등을 붙여 넣는다.
   - 고객 이름·연락처·주문번호, 회사 기밀은 지우거나 가린 뒤 붙여 넣는다.
4. Gemini 또는 Claude 새 대화에 붙여 넣고 결과를 직접 확인한다.
   - 한쪽이 사용량 한도에 걸리면 같은 프롬프트를 다른 쪽에 붙여 넣어 이어 한다.
5. 결과가 마음에 들지 않으면 대화로 다듬고, 자주 고치는 부분은 템플릿 자체를 고쳐 버전을 올린다.

## 1. 회의록정리_팀공유용_v1

- 용도: 회의 메모를 팀이 함께 보는 회의록으로 정리
- 빈칸: [회사·팀], [읽는 사람], [분량]

```
너는 [회사·팀]의 회의록 담당자야.
아래 회의 메모를 읽고 회의록으로 정리해 줘.
- 읽는 사람: [읽는 사람]
- 분량: [분량]
- 항목: 회의 개요(날짜·참석자) / 논의 내용 / 결정 사항 / 할 일 표(할 일·담당자·기한)
- 메모에 없는 내용은 지어내지 말고 '확인 필요'라고 표시해 줘.

[회의 메모]
(여기에 회의 메모를 붙여 넣기)
```

예: [회사·팀] = 바다결 온라인 마케팅팀, [읽는 사람] = 회의에 참석하지 못한 팀원, [분량] = A4 한 쪽 이내

## 2. 고객문의답변_자사몰_v1

- 용도: 자사몰·오픈마켓 고객 문의에 보낼 답변 초안
- 빈칸: [회사], [말투], [분량], [담당 부서]

```
너는 [회사]의 고객 상담 담당자야.
아래 고객 문의에 보낼 답변을 써 줘.
- 말투: [말투]
- 분량: [분량]
- 순서: 문의 내용 확인 → 답변 또는 처리 방법 → 추가 안내 → 마무리 인사
- 환불·보상·배송 일정처럼 회사가 정해야 하는 내용은 약속하지 말고, [담당 부서]에서 확인한 뒤 안내한다고 써 줘.
- 고객 이름·연락처·주문번호는 쓰지 말고 '고객님'이라고 불러 줘.

[고객 문의]
(여기에 문의 내용을 붙여 넣기 — 이름·연락처·주문번호는 지우고)
```

예: [회사] = 바다결, [말투] = 정중하고 따뜻하게, [분량] = 4~5문장, [담당 부서] = 경영지원팀

---

## 3. 보도자료초안_신제품_v1

- 용도: 신제품·행사 소식을 알리는 보도자료 초안
- 빈칸: [회사], [알릴 내용], [독자], [분량]

```
너는 [회사]의 홍보 담당자야.
아래 자료로 보도자료 초안을 써 줘.
- 알릴 내용: [알릴 내용]
- 독자: [독자]
- 분량: [분량]
- 구성: 제목 / 부제 / 첫 문단(누가·언제·어디서·무엇을) / 본문 / 회사 소개 한 문단
- 자료에 없는 숫자·인용문·수상 경력은 만들지 말고 '(확인 필요)'로 남겨 둬.

[자료]
(여기에 사실 자료를 붙여 넣기 — 출시일, 가격, 구성, 판매처 등)
```

예: [회사] = 바다결, [알릴 내용] = 추석 선물 세트 출시, [독자] = 지역 신문 기자, [분량] = A4 한 쪽

## 4. 주간보고_팀장보고용_v1

- 용도: 이번 주 업무 메모를 주간 보고로 정리
- 빈칸: [팀], [읽는 사람], [분량]

```
너는 [팀] 소속 직원이야.
아래 이번 주 업무 메모로 [읽는 사람]께 올릴 주간 보고를 써 줘.
- 분량: [분량]
- 항목: 이번 주 한 일 / 성과·수치 / 문제와 도움이 필요한 일 / 다음 주 계획
- 각 항목은 글머리표로 쓰고, 숫자는 메모에 있는 것만 써 줘. 없는 숫자는 '확인 필요'.

[업무 메모]
(여기에 이번 주 업무 메모를 붙여 넣기)
```

예: [팀] = 바다결 온라인 마케팅팀, [읽는 사람] = 팀장님, [분량] = 항목당 2~3줄

---

## 템플릿 점검표 (저장하기 전에)

- [ ] 이름과 용도가 있다 (예: 주간보고_팀장보고용_v1)
- [ ] 역할·맥락이 고정 부분에 들어 있다
- [ ] 바뀌는 부분이 [ ] 빈칸으로 분명하다
- [ ] 출력 형식(항목·표)과 분량이 정해져 있다
- [ ] 주의 사항이 있다 (지어내지 않기, 개인정보 넣지 않기, 약속하지 않기)
- [ ] 쓰는 법이나 좋은 결과 예시가 한 줄 이상 있다
