# 점검 루브릭 (후기 한 건마다 5개 기준, 10건이면 50점 만점)

| 기준 | 통과 조건 | 확인 방법 |
|---|---|---|
| ① 유형 | 칭찬·불만·제안·보통 중 알맞게 분류했다 | 별점과 후기 문장을 함께 본다 |
| ② 분량 | 답글이 2~3문장이다 | 문장 수를 센다 |
| ③ 구체성 | 후기 내용을 한 가지 이상 구체적으로 짚었다 | 후기 속 단어(양, 포장, 유통기한…)가 답글에 있는지 |
| ④ 약속·사실 | 지키지 못할 약속(환불·보상·출시)이나 지어낸 제품 정보가 없다 | 회사가 정하지 않은 내용이 있는지 |
| ⑤ 응대 | 유형에 맞게 응대했다 (불만=사과+안내, 칭찬=감사, 제안=감사+전달, 보통=감사+개선 의지) | 유형과 답글의 첫 문장을 비교한다 |

표 형식(번호·유형·요약·답글)이 지켜졌는지도 함께 본다.

# 후기분류답글_v2 (루브릭 점검 후 고친 템플릿)

고친 내용: 유형에 '보통' 추가 / 답글 분량·첫마디 지정 / 약속·지어낸 정보 금지 / 확인 필요 열 추가 / 답글 예시 1개

```
너는 부산의 건강 간식 회사 '바다결'의 고객 응대 담당자야.
아래 [후기 목록]을 읽고 다음 순서대로 해 줘.
1단계: 각 후기를 칭찬 / 불만 / 제안 / 보통 중 하나로 분류
  (보통 = 좋지도 나쁘지도 않은 평가. 예: 무난해요)
2단계: 후기 내용을 한 줄로 요약
3단계: 고객에게 남길 답글 초안 작성
  - '고객님'으로 시작해 2~3문장, 후기 내용을 한 가지 이상 구체적으로 언급
  - 불만에는 사과 + "고객센터로 알려 주시면 확인해 드리겠습니다" 안내
  - 환불·교환·보상·신제품 출시는 약속하지 말 것
  - 후기에 없는 제품 정보(원산지·성분 등)는 쓰지 말 것
  - 답글 예시) 후기: 배송 중에 봉투가 터져서 왔어요
    → 고객님, 봉투가 터진 채로 받으셔서 많이 불편하셨죠. 정말 죄송합니다. 사진을 고객센터로 보내 주시면 바로 확인해 드리겠습니다.
결과는 표로 정리해 줘. 열: 번호 | 유형 | 요약 | 확인 필요 | 답글 초안
'확인 필요' 열에는 유통기한·파손·이물질처럼 담당 부서가 바로 확인해야 하는 후기에만 ● 표시.

[후기 목록]
(여기에 reviews_q3_10.txt 내용을 붙여 넣기)
```

# 게시 전에 사람이 확인할 것

- 제품명·채널이 후기와 맞는가
- 회사 정책(환불·교환)과 어긋나는 문장이 없는가
- 고객을 알아볼 수 있는 정보가 들어가지 않았는가
- 어색하거나 같은 표현이 반복되는 답글은 없는가
- 팀장 확인을 받았는가
