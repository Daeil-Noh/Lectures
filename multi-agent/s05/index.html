LLM 심사: 기준표 하나, 점수 하나

JUDGE = {'name': 'grade', 'input_schema': {'type': 'object',
  'properties': {
    'factual':      {'type': 'number'},   # 0~1 사실 정확성
    'citation':     {'type': 'number'},   # 0~1 인용이 원문과 맞나
    'completeness': {'type': 'number'},   # 0~1 물은 것을 다 답했나
    'source':       {'type': 'number'},   # 0~1 근거 자료의 질
    'efficiency':   {'type': 'number'},   # 0~1 도구를 알맞게 썼나
    'score':        {'type': 'number'},   # 0~1 종합
    'pass':         {'type': 'boolean'},
    'evidence':     {'type': 'string'}}}}
  • 항목: 사실 · 인용 · 완결성 · 출처 품질 · 도구 효율
  • 호출 한 번에 0~1 점수와 통과 여부 — 여러 심사를 나누는 것보다 일관됐다는 보고
  • 근거(evidence)를 요구해 사람이 다시 확인할 수 있게
  • 코드로 셀 수 있는 것(인용 id 존재, 형식)은 코드로 먼저
