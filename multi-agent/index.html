멀티 에이전트 시스템 구축

여러 LLM 에이전트가 역할을 나눠 일하는 시스템을 언제 써야 하는지 판단하고, 파이썬 코드로 구조를 들여다보고 고쳐 보고, 코딩 에이전트 여럿을 연구 환경에 들이고, 결과를 평가 · 관측 · 방어하는 법까지 초급부터 고급으로 다룹니다.

  • 초급 → 중급 → 고급
  • Colab · Claude API (유료 키)
  • Claude Code · git worktree
  • 미니 프로젝트 발표

교육 목표

  1. 멀티 에이전트가 주는 이득(컨텍스트 격리 · 병렬 · 역할 분리)과 비용 · 실패 유형을 근거로, 주어진 과제에 맞는 구조를 고를 수 있다.
  2. 프레임워크 없이 짠 도구 사용 루프와 오케스트레이터–워커 코드를 읽고 고쳐 보며 구조를 설명하고, 같은 시스템을 프레임워크로 옮길 수 있다.
  3. 컨텍스트 전달 · 흐름 제어 · 작성–검토 루프 · MCP를 이용해 에이전트 사이의 연결을 설계할 수 있다.
  4. 규칙 파일 · 서브에이전트 · 권한 · 훅과 Orca 같은 도구로 코딩 에이전트 여럿이 일하는 연구 개발 환경을 꾸릴 수 있다.
  5. 추적 기록 · 평가 기준표 · 다층 방어 · 비용 손잡이로 시스템의 신뢰성과 효율을 보일 수 있다.
