# 머신러닝 알고리즘, 그림으로 이해하기 — 선형회귀부터 앙상블까지

동의대학교 인공지능학과 · 노대일 교수 · 특강 (약 3시간, 휴식 2회 포함)  
수식 대신 그림과 비유로 대표 머신러닝 알고리즘을 설명하는 슬라이드입니다. 수식은 꼭 필요한 세 곳(직선, 여러 요인의 합, S자 곡선)에만 한 줄씩 나옵니다.

**보기**: https://daeil-noh.github.io/Lectures/ml-algorithms/ (로컬에서는 `index.html`을 브라우저로 열기)

## 구성 (52장)

| 구역 | 내용 | 직접 해 보기 |
|---|---|---|
| 01 큰 그림 | 프로그래밍 vs 머신러닝, 회귀와 분류, 학습 = 틀린 만큼 고치기, 훈련/테스트 분리 | |
| 02 회귀 | 선형회귀, 다중회귀(해석·다중공선성·상관≠인과), 다항회귀와 과적합, 규제(릿지·라쏘·엘라스틱넷) | 1 직선 맞추기 · 2 집값 계산기 · 3 과적합과 규제 |
| 03 분류 | 로지스틱 회귀(확률과 판정 기준), KNN, 결정트리, SVM과 커널 트릭 | 4 합격 확률과 기준 · 5 KNN의 K · 6 트리 깊이 |
| 04 앙상블 | 집단지성, 보팅, 배깅·부트스트랩, 랜덤 포레스트, AdaBoost, 그래디언트 부스팅, XGBoost·LightGBM·CatBoost, 스태킹 | 7 다수결의 힘 · 8 랜덤 포레스트 · 9 그래디언트 부스팅 |
| 05 정리 | 알고리즘 지도, 무엇부터 써 볼까, 종합 퀴즈, scikit-learn 사용 모양 | |

발표자 노트의 예정 시간 합계는 약 180분입니다(휴식 10분 × 2 포함).

## 조작법

`←` `→` 넘기기 · `N` 발표자 노트(장별 예정 시간·누적 시간·경과 시간) · `T` 강의 시계 시작/정지 · `O` 슬라이드 목록 · `F` 전체 화면 · 주소 끝 `#12`로 바로 이동 · 브라우저 인쇄(PDF 저장) 시 한 장씩 출력
