평수가 넓을수록 비싸다 — 이 경향을 직선 하나로 요약합니다.

점선 = 실제 값과 직선의 차이(오차, 잔차)

"가장 잘 지난다" = 이 점선들이 전체적으로 가장 짧은 직선. 보통 길이를 제곱해 더한 값이 가장 작은 선을 고릅니다(최소제곱법).

  • 판정은 로지스틱과 같은 모양: w·x + b가 양수면 A, 음수면 B

  • 조건: 모든 점이 도로 밖에 yi(w·xi + b) ≥ 1  (y = +1 또는 −1)
현실 버전: 소프트 마진
최소화  ½‖w‖2 + C Σ ξi
ξ = 점이 도로를 침범한 정도, C = 침범 벌점. C가 크면 엄격 → 과적합 쪽, 작으면 너그러움.

다수결의 힘을 계산해 보면

P(다수결 정답) =  Σk > M/2MCk pk(1 − p)M−kM개 중 k개가 맞힐 확률(이항분포)을 '과반'인 경우만 더함
p = 0.65, M = 3
셋 다 맞힘 0.653 = 0.27
둘만 맞힘 3 × 0.652 × 0.35 = 0.44
합 0.72 > 0.65 · M = 51이면 약 0.99 (데모 값)

위 계산은 모델들이 서로 독립일 때만 맞습니다. 닮은 정도 ρ가 있으면, M개 예측의 평균이 흔들리는 정도는

분산 = ρσ2 + (1 − ρ)σ2M

M을 아무리 늘려도 둘째 항만 사라지고 ρσ2는 남는다 → 닮은 정도 ρ를 낮추는 것이 핵심. 배깅과 랜덤 포레스트의 '무작위'가 하는 일.

AdaBoost의 두 식: 발언권과 오답 가중치

발언권 α = ½ ln 1 − εε
가중치 갱신 틀린 점 × eα, 맞힌 점 × e−α
최종 판정 H(x) = 부호( Σm αm hm(x) )

ε = 이번 모델의 (가중치를 반영한) 오답률, hm(x) = +1 또는 −1

계산해 보기
ε = 0.3 → α = ½ ln(0.7/0.3) ≈ 0.42
틀린 점 × e0.42 ≈ 1.53, 맞힌 점 × e−0.42 ≈ 0.66
→ 다음 모델이 볼 때 틀린 점이 약 2.3배 무거워진다.

ε = 0.1 → α ≈ 1.10 (잘한 모델, 큰 발언권)
ε = 0.5 → α = 0 (동전 던지기 수준, 발언권 없음)

그래디언트 부스팅: 남은 오차를 다음 나무가 메운다

  1. 첫 예측은 대충(예: 평균값)
  2. 각 데이터의 남은 오차(정답 − 지금 예측)를 계산
  3. 새 나무는 정답이 아니라 이 남은 오차를 맞히도록 학습
  4. 새 나무의 답을 조금만(학습률) 더해 예측을 고친다 → 2로
학습률 = 한 번에 얼마나 고칠지. 작게 여러 번이 보통 더 정확하지만 나무가 많이 필요. 너무 오래 하면 과적합 → 실전 점수가 나빠지기 시작할 때 멈춘다(조기 종료).
머신러닝 알고리즘 특강 · 수학 포함판
골프 비유: 첫 샷 후 남은 거리만큼 다음 샷, 또 남은 만큼 퍼팅. '그래디언트'는 오차를 줄이는 방향이라는 뜻 — 제곱 오차를 쓸 때는 그 방향이 바로 남은 오차라서 위 설명과 같아진다. 수식은 생략.

그래디언트 부스팅을 식으로

Fm(x) = Fm−1(x) + η · hm(x)지금까지의 예측 + 학습률 × 새 나무의 답
F0 = ȳ시작은 정답들의 평균
ri = yi − Fm−1(xi)남은 오차
hmr을 맞히도록 학습한 작은 나무

왜 '그래디언트'? L = ½(y − F)2을 F로 미분하면 −(y − F). 남은 오차 = 오차를 줄이는 방향(음의 기울기) → 예측값 자체에 경사하강법을 하는 것.

계산해 보기 (나무가 r을 정확히 맞힌다고 할 때)
정답 y = 10, F0 = 6, η = 0.5
r = 4 → F1 = 6 + 0.5×4 = 8
r = 2 → F2 = 9 → F3 = 9.5 → …
매번 남은 거리의 절반씩 → 10에 다가간다.
