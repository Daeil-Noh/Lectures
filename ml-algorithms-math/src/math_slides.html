가장 낮은 곳 찾기: 경사하강법

w ← w − η · ∂MSE∂w기울기의 반대 방향으로, 학습률 η만큼 조금 움직인다
  • 기울기(미분) = 지금 자리에서 w를 늘리면 오차가 얼마나 오르는지
  • 기울기가 양수면 왼쪽, 음수면 오른쪽으로 → 언제나 내리막

선형회귀는 공식 한 번으로도 풀립니다 (w = Σ(x−x̄)(y−ȳ) ÷ Σ(x−x̄)2). 그래도 경사하강법을 배우는 이유: 로지스틱 회귀, 부스팅, 신경망까지 거의 모든 모델이 이 방법으로 학습합니다.

도로 폭을 식으로

경계 w·x + b = 0
도로 가장자리 w·x + b = ±1
도로 폭 2‖w‖‖w‖ = 가중치 벡터의 길이
  • 판정은 로지스틱과 같은 모양: w·x + b가 양수면 A, 음수면 B
  • 도로를 넓히기 = ‖w‖를 작게 — 릿지 규제와 같은 생각
  • 조건: 모든 점이 도로 밖에 yi(w·xi + b) ≥ 1  (y = +1 또는 −1)
현실 버전: 소프트 마진
최소화  ½‖w‖2 + C Σ ξi
ξ = 점이 도로를 침범한 정도, C = 침범 벌점. C가 크면 엄격 → 과적합 쪽, 작으면 너그러움.
머신러닝 알고리즘 특강
선택 내용으로 빠르게 넘어가도 된다. 핵심 한 문장: '여백 최대화 = 가중치 길이 최소화'. 커널 트릭은 식 안의 내적 w·x를 다른 '닮음 함수'로 바꿔치기하는 것.
