# 머신러닝 알고리즘, 그림과 수식으로 — 수학 포함판

동의대학교 인공지능학과 · 노대일 교수 · 특강 (약 3시간, 휴식 2회 포함)  
[그림만 있는 버전](../ml-algorithms/)과 내용·데모가 같고, 각 알고리즘 뒤에 **수학 슬라이드 15장**과 경사하강법 데모 하나를 더했습니다. 고등학교 수학(Σ, 지수·로그, 제곱근) 수준입니다.

**보기**: https://daeil-noh.github.io/Lectures/ml-algorithms-math/

## 더해진 수학 (오른쪽 위 `수학` 표시가 붙은 장)

| 구역 | 수학 슬라이드 |
|---|---|
| 01 큰 그림 | 기호표 (x, y, ŷ, w, b, Σ, η, λ, p) |
| 02 회귀 | 평균제곱오차(MSE) · 경사하강법 + **직접 해 보기 2: 학습률 바꾸기** · 다중회귀 식과 표준화 · 릿지/라쏘 식과 원·마름모 그림 |
| 03 분류 | 시그모이드와 로그 오즈 · 로그 손실 · 유클리드 거리와 표준화 · 지니 불순도 계산 · SVM 도로 폭 2/‖w‖와 소프트 마진 |
| 04 앙상블 | 다수결 정확도(이항분포)와 평균의 분산 ρσ² + (1−ρ)σ²/M · 부트스트랩 (1−1/n)ⁿ ≈ 0.37 · AdaBoost의 α와 가중치 갱신 · 그래디언트 부스팅 식 |
| 05 정리 | 오늘의 식 한 장 (인쇄용 요약) |

슬라이드마다 손으로 따라 할 수 있는 숫자 예가 있습니다(예: 집값 계산기 기본값 4.23억, 지니 0.5 → 0.17, AdaBoost ε = 0.3 → α ≈ 0.42).

## 시간

68장, 발표자 노트 예정 시간 합계 180분. 원본보다 장이 16장 늘어서 원본 장들의 예정 시간을 약 70%로 줄였습니다. 시간이 모자라면 SVM 식, 로그 오즈, AdaBoost 식 장은 건너뛰어도 흐름이 끊기지 않습니다.

## 파일

```
ml-algorithms-math/
├─ index.html          슬라이드 (src/build.py가 만든 결과물 — 직접 고치지 말 것)
├─ math-demo.js        경사하강법 데모
└─ src/
   ├─ build.py         원본 + 수학 슬라이드를 합쳐 index.html 생성
   ├─ math_slides.html 수학 슬라이드 (어느 장 뒤에 넣을지 표시 포함)
   └─ extra.css        수식 표기 스타일
```
나머지 데모는 `../ml-algorithms/demo.js`를 함께 씁니다. **원본 슬라이드를 고친 뒤에는** 저장소 최상위에서 다음을 실행하면 수학 포함판에도 반영됩니다.

```bash
python3 ml-algorithms-math/src/build.py
node tools/check_lesson.js ml-algorithms-math/index.html /tmp/shots   # 넘침·오류 점검
```
